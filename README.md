# LoAT -- the Loop Acceleration Tool

LoAT (**Lo**op **A**cceleration **T**ool) is a fully automated tool to analyze *transition systems* and *Constrained Horn Clauses (CHCs)*.

For more information, please visit [LoAT's website](https://loat-developers.github.io/LoAT/).
